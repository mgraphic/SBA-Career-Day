# School Angular Demo Project

Welcome to the South Bay Church Career Day Demo App! This project is designed to introduce high school students to web development using Angular. It features interactive examples to help students understand the basics of frontend and backend development, user interactivity, and deployment.

## Project Overview

This demo app includes:

- **Live Reactions Counter**: See how user actions update the UI instantly.
- **Frontend vs Backend Game**: Learn the difference between frontend and backend tasks with a fun quiz.
- **Fake API Demo**: Simulate how a frontend communicates with a backend server.
- **Theme & Style Switcher**: Experiment with colors and see how code changes affect the look of the app.
- **Deploy Button**: Visualize the process of deploying an app to the internet.

## How to Run the Demo

1. **Install Node.js** (if not already installed): [Download Node.js](https://nodejs.org/)
2. **Install dependencies**:
    ```bash
    cd app
    npm install
    ```
3. **Start the development server**:
    ```bash
    npm start
    ```
4. Open your browser and go to [http://localhost:4200](http://localhost:4200)

## Project Structure

- `app/` — Main Angular app source code
- `demo/` — Additional HTML demo files
- `index.html` — Project landing page

## Learning Goals

- Understand the basics of web app development
- See real-time UI updates with Angular
- Learn the difference between frontend and backend
- Experience a simulated deployment process

## For Presenters

This app is designed for live classroom demos. Use the interactive features to engage students and explain key concepts in web development. Encourage students to guess answers, try the API demo, and experiment with styles.
